# SLR Group Website

SLR Group ke liye multi-section website with backend APIs.

## Features
- Dedicated pages for:
  - Hospital (`/hospital`)
  - Lawn (`/lawn`)
  - School (`/school`)
- Home page with inquiry form
- Backend API endpoints:
  - `GET /api/sections`
  - `GET /api/sections/:name`
  - `POST /api/inquiry`
  - `GET /api/inquiry`

## Run Locally
```bash
npm start
```

Then open: `http://localhost:3000`
